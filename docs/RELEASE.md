# Release Process

The project has no installable release yet.

## Release Readiness

A release can be considered when the relevant milestone has:

- Documented scope
- Reviewed changes
- Passing repository checks
- Installation or verification notes
- Known limitations listed

## Versioning

Use milestone-aligned versions until the project reaches a stable runtime:

```text
0.1.x hardware access and firmware research
0.2.x display engine and MQTT proof of concept
0.3.x Home Assistant integration
0.4.x smart alarm
0.5.x Music Assistant
1.0.x full companion release
```

## Artifacts

Early releases should publish documentation only. Firmware images, binaries, or
device packages require explicit license review before distribution.
