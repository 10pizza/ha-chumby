# Example boot-diagnostics.txt

This is an example of the expected Sprint 9 diagnostics file shape. It is not a real hardware log.

On real hardware, `installer/overlay/ha-chumby/start.sh` writes the live log to:

/tmp/ha-chumby.log

and copies it to the USB stick as:

/ha-chumby/boot-diagnostics.txt
