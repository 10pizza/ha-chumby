# Firmware

This directory is for Chumby firmware, boot, USB, SSH, and hardware research.

Do not commit proprietary firmware images unless their license explicitly allows
redistribution.

Initial research topics:

- Stock firmware layout
- USB boot process
- SSH access
- Kernel and userspace versions
- Available package managers or build paths
- Framebuffer device paths
- Touchscreen input device paths
- Audio device paths
- Python availability
- SDL2 availability
