# Support

This project is in early research and infrastructure setup.

## Getting Help

- Use GitHub issues for reproducible bugs, feature requests, and sourced
  research notes.
- Include the Chumby model, hardware revision, firmware version, and exact
  commands or observations when reporting hardware behavior.

## Not Supported Yet

- End-user installation
- Production bedside use
- Custom firmware images
- Home Assistant add-on installation
- Music Assistant playback
