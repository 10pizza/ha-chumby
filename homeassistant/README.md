# Home Assistant

This directory is for Home Assistant integration design, MQTT discovery notes,
example automations, and future custom integration work.

Home Assistant is the authoritative system for:

- Alarm rules
- Weather providers
- Calendar providers
- School schedule data
- Notification routing
- Music Assistant state
- Automation decisions

The Chumby should receive prepared state over MQTT and publish local interaction
events back to Home Assistant.

No Home Assistant integration code exists yet.
